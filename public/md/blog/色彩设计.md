## 色彩三要素

H S B

+   H: 色相
+   S: 饱和度 x轴
+   B: 明亮度 y轴



## 六大色调

### 纯色调

S和B都很高，九宫格右上

+   刺激、直接、活力

背景不应当用纯色调



### 明色调

九宫格中上，B明亮度高，S饱和度中

+   年轻、活力



### 淡色调

九宫格左上，B高，S底

+   天真、轻快、清爽、女性



### 白色调

淡色调的左上

+   文艺、素雅、简洁、干净
+   无趣、单调、缺乏个性



### 灰色调

九宫格中层，亮度居中 

+   成熟、稳重、优雅、文艺
+   脏



### 暗色调

九宫格底层，亮度低

+   品质、历史、力量、厚重、地位
+   压抑



## 色彩平衡



### 色调平衡

+   所有画面都必须满足此平衡
+   画面有层次感
+   突出主题和文字

一个画面不能只有一种色调、必须要有两种以上互相平衡，要想文字被人不费劲的看那么文字的颜色和底色必须足够区分：黑底白字、白底黑字。但是也不能过于强烈：红底蓝字

明色、淡色<----->灰色、暗色



### 冷暖平衡

色彩不应过冷过热导致情感失衡

特殊情况下可以：夏日的清凉、冬日的温暖

H：180°为最冷的青色，0为最热的红色



### 互补平衡

平衡色彩刺激带来的心理失衡，也叫生理补色

眼睛受到一种色彩的刺激后，心里会产生平衡这种色彩刺激的欲望

这种平衡需要通过这种颜色的互补色来完成  红-绿，黄-蓝，橙-蓝



### 花色和纯色平衡

背景花里胡哨，文字应当用纯色，白色最佳



### 有彩色和无彩色的平衡

无彩色： 黑白灰

有彩色： 有色相



### 面积平衡

+   70%主色
+   25%辅助色
+   5%点缀色



## 主色辅色点缀色

一个画面应有三种色相

### 主色

定基调，决定基调和风格

+   饱和度高一般为主色
+   颜色重的一般为主色
+   面积大的为主色



### 辅色

搭配主色：

+   同类色
+   邻近色

+   互补色
+   对比色



### 点缀色

强调作用、突出重点

明度高的背景：点缀色明度低或者饱和度高

明度低的背景：点缀色明度高或者饱和度高









## 配色技巧

### 对比色

色环上120°

优点：强烈

缺点：视觉疲劳

解决方法：

	+ 降低或提高双方色调
	+ 减少副色面积
	+ 两种颜色中间加黑色或者白色
