# 项目热部署

1.   添加依赖

     ```xml
     <dependency>
         <groupId>org.springframework.boot</groupId>
         <artifactId>spring-boot-devtools</artifactId>
         <optional>true</optional>
     </dependency>
     ```

2.   编译器设置

     `ctrl+alt+shift+/`打开维护界面，选择注册表

     ![image-20220621193514055](https://cdn.jsdelivr.net/gh/liu2ye/imageService/img/image-20220621193514055.png)

​		将compiler.automake.allow.when.app.running选中![image-20220621193644758](https://cdn.jsdelivr.net/gh/liu2ye/imageService/img/image-20220621193644758.png)

3.   运行

     修改后等待即可自动编译
