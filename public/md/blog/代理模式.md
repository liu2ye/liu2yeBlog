# 代理模式

## 代理模式的好处

+ 可以使真实角色的操作更加纯粹！不用去关注一些公共的业务
+ 实现了业务的分工
+ 当公共业务发生扩展时，方便集中管理

## 静态代理

### 静态代理的实现

+ 写一个代理类，这个代理类要**implements**它所代理的接口（以下称为**接口A**）

+ 这个代理类有一个字段是个接口，这个接口的类型就是接口A，这个字段要有set方法

+ 实现接口A的方法，在方法体里要调用字段的该方法，方法体里可以写其他语句

+ 代理类和接口A的代码如下：

    ```java
    public class 接口AProxy implements 接口A{
        private 接口A 接口a;

        public void set接口A(接口A 接口a) {
            this.接口a = 接口a;
        }

        @Override
        public void add() {
            //其他语句....
            接口a.add();
            //其他语句....
        }
    }

    public Interface 接口A {
        void add();
    }
    ```

+ 使用这个代理类时，只要为它传入一个接口A的实现类，就可以代理这个实现类了

    ```java
    /* 使用代理类来代理方法
        接口AProxy p = new 接口AProxy();
        p.set(new 接口AImpl);
        p.add();
    */
    
    public class 接口AImpl implements 接口A{
        @Override
        public void add() {
            ....
        }
    }
    
    ```

## 动态代理

### 动态代理的好处

+ 静态代理实现接口A的所有方法来实现代理，如果要对所有方法进行同样的修改就会有大量重复的代码
+ 通过动态代理可以很方便的对被代理类的所有方法进行同一的处理
+ **动态的是方法**

### 动态代理的实现

1. 基于接口   **JDK动态代理**
2. 基于类   **cglib**
3. java字节码实现  **javasist**

需要了解两个类：**Proxy**  **InvocationHandler**

通过JDK动态代理来实现：

+ 与静态代理一样，写一个动态代理类，不过不用实现要代理的接口，要实现InvocationHandler

+ 与静态代理一样，将被代理的接口作为字段，并给它set方法

+ 实现InvocationHandler的invoke方法

+ 写一个getProxy()方法来获取被动态创建的代理类

+ 详细代码如下：

  ```java
  public class ProxyInvocationHandler implements InvocationHandler {
      private UserService target;
  
      public void setTarget(UserService target) {
          this.target = target;
      }
  
      public UserService getProxy() {
          return (UserService) Proxy.newProxyInstance(this.getClass().getClassLoader(), 					target.getClass().getInterfaces(), this);
      }
  
      @Override
      public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
          System.out.println("调用了方法: " + method.getName());
          System.out.println("参数: " + Arrays.toString(args));
          Type t = method.getAnnotatedReturnType().getType();
          System.out.println("返回值类型" + t.getTypeName());
          //调用代理的方法
          Object result = method.invoke(target, args);
          //其他语句....
          return result;
      }
  }
  ```

+ 使用动态代理的语句如下：

  ```java
  	//动态代理
      ProxyInvocationHandler pih = new ProxyInvocationHandler();
      pih.setTarget(new UserServiceImpl());
      UserService proxy = pih.getProxy();
      proxy.add();
  ```
